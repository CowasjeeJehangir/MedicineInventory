# 💊 MedicineInv — Pharmacy Inventory Management System

MedicineInv is a **web-based pharmacy inventory and management system** 
designed to help manage medicine stock, staff, and patient details efficiently.  
It provides a secure and easy-to-use interface for both administrators and staff members.

---

## 📁 Project Structure
<pre> MedicineInv/ 
├── backend/              # Backend API (Flask/FastAPI/Express — depending on your stack)
├── frontend/             # Frontend application (React/Vue/Angular)
├── .gitignore            # Ignored files for git
├── Dockerfile.backend    # Dockerfile for backend container
├── Dockerfile.frontend   # Dockerfile for frontend container
├── docker-compose.yml    # Compose file for full-stack deployment
├── inventory.db          # SQLite database (for local testing only)
├── medicineinventory.pdf # Project proposal / documentation
├── package-lock.json     # Dependency lock file (possibly from frontend)
  </pre>

---

## 🚀 Features

### 👩‍⚕️ Admin
- Add and manage users (staff)
- Add, edit, and remove medicines
- View and update stock levels
- Manage patient details
- Generate inventory and patient reports

### 👨‍🔬 Staff
- Limited access for day-to-day operations
- Check medicine availability
- Update patient information (if permitted)
- Record dispensed medicines

---

## 🧩 Tech Stack
- **Frontend:** (e.g., React / Vue / Angular)
- **Backend:** (e.g., Flask / FastAPI / Node.js / Express)
- **Database:** SQLite (for testing) → can be upgraded to MySQL/PostgreSQL
- **Containerization:** Docker & Docker Compose

---

## 🐳 Deployment (via Docker)

To run both frontend and backend together using Docker Compose:

```bash
# Build and start containers
docker-compose up --build
```

Then open your browser and visit:
```bash
Frontend: http://localhost:3000
Backend API: http://localhost:8000
```

## 🧠 Development Setup (Manual)

If you prefer to run services manually:

### Backend
```bash
cd backend
pip install -r requirements.txt   # or npm install if Node.js
python app.py                     # or npm start
```

### Frontend
```bash
cd frontend
npm install
npm start
```
